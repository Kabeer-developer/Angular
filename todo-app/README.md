# Todo App

A small Angular Todo app built with standalone components, TypeScript, and Tailwind CSS. Todos are kept in memory while the page is open.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/`.

## Use

Enter a task and select **Add task**. Use the checkbox to mark it complete, or select **Delete** to remove it.

## Verify

```bash
npm test
npm run build
```
